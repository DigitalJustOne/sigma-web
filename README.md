# SIGMA Parafinado y Empaques

Sitio web corporativo de **SIGMA Parafinado y Empaques**, empresa colombiana especializada en empaques de papel para alimentos. Soluciones biodegradables, parafinadas y personalizadas para restaurantes, comidas rápidas, panaderías y negocios de alimentos.

## 🚀 Demo

[Ver sitio en vivo](https://digitaljustone.github.io/sigma-web)

## 📋 Características

- ✅ Diseño 100% responsive (mobile-first)
- ✅ Efecto glassmorphism en navbar al hacer scroll
- ✅ Animaciones suaves con Intersection Observer
- ✅ Catálogo completo de productos
- ✅ Formulario de cotización interactivo
- ✅ Integración con WhatsApp
- ✅ Tipografía Outfit de Google Fonts
- ✅ Estilos con Tailwind CSS v3

## 🛠️ Tecnologías

- **HTML5** — Estructura semántica
- **CSS3** — Custom properties, flexbox, grid, animaciones
- **JavaScript** — Interactividad, observadores de scroll, formularios
- **Tailwind CSS** — Framework de utilidades (vía CDN)
- **Google Fonts** — Tipografía Outfit

## 🚦 Cómo usar

### Opción 1 — Abrir directamente

Abre `index.html` en cualquier navegador moderno.

### Opción 2 — Servidor local

```bash
node serve.js
```

Luego abre `http://localhost:8000` en tu navegador.
